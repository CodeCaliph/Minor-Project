Disentangling Semantic Knowledge and Memorisation in LLM-Based Data Cleaning: A Benchmark on Synthetic vs. Real Tabular Data

Al Ayaan Ansari (23BCS034) · Mohd Adnan Khan (23BCS042) · Supervisor: Dr. Faiyaz Ahmad

When a large language model fills in missing values better than classical methods, is it because it understands the data, or because it has already seen that dataset during training? This project designs a controlled benchmark to tell the two apart.
